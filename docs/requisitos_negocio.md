# Documento de Requisitos do Sistema
## Sistema: Plataforma de Agendamento Online "AgendaFácil"

---

## 1. Requisitos Funcionais (RF)

**RF01** – O sistema deve permitir que o usuário realize cadastro informando nome, e-mail e senha.

**RF02** – O sistema deve permitir que o usuário realize login utilizando e-mail e senha cadastrados.

**RF03** – O sistema deve permitir que o usuário visualize os horários disponíveis para agendamento.

**RF04** – O sistema deve permitir que o usuário realize, edite e cancele agendamentos.

---

## 2. Requisitos Não Funcionais (RNF)

**RNF01** – O sistema deve responder às requisições do usuário em no máximo 2 segundos em 95% dos casos.

**RNF02** – O sistema deve estar disponível 99% do tempo mensal, exceto em períodos de manutenção programada.


---

## 3. Regras de Negócio (RN)

**RN01** – O usuário poderá realizar no máximo 3 agendamentos ativos por dia.

**RN02** – Cancelamentos só poderão ser realizados com no mínimo 2 horas de antecedência do horário agendado.

---

## 4. Observações

Este documento descreve requisitos iniciais fictícios e pode ser atualizado conforme evolução do projeto.
